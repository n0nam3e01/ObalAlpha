# Homepage Redesign Implementation Plan

**Goal:** Современная, аккуратная главная с сохранением рабочего каталога и бронирования.
**Architecture:** React-компонент вводного блока/пустого состояния, изолированные стили каталога, адаптивная навигация в существующем AppHeader.
**Tech Stack:** React/Vite, plain CSS, существующие SVG и theme tokens.

- [x] Пересобрать сетку, типографику, фильтры, карточки и навигацию для desktop/mobile.
- [x] Проверить обе темы на 320/390/1440px, отсутствие горизонтальной прокрутки, доступность фильтров и первый товар в viewport.
