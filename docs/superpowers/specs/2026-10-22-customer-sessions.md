# Отзывные сессии покупателей

Продолжение утверждённого исправления E1, без смены JWT/Express/Prisma на Supabase Auth.

- Access JWT HS256 с userId/sid, сроком 15 минут. Проверка серверной сессии при каждом защищённом запросе; старые JWT без sid отклоняются.
- Refresh: случайный секрет 32 байта, только HttpOnly-cookie `/api/auth`, срок 7 суток, в БД SHA-256. Одна сессия может выдавать несколько access JWT до истечения или отзыва. Refresh не ротируется при каждом чтении, чтобы параллельные вкладки не инвалидировали друг друга. Выход отзывает сессию немедленно; отдельный маршрут отзывает все сессии пользователя.
- Cookie Secure в production; SameSite=Lax по умолчанию, None только явной настройкой для разнесённых доменов. Проверка Origin на cookie-маршрутах. CORS допускает credentials только для явного списка origin. Для браузеров, блокирующих third-party cookies, нужен общий site/proxy; это требование размещения, а не повод вернуться к localStorage.
- Frontend хранит access в памяти, удаляет legacy localStorage, при старте восстанавливает вход через refresh. Один параллельный refresh; не больше одного повтора API-запроса после 401. Выход не объявляется успешным при ошибке сети.
- Refresh не меняет текущую личность незаметно: если cookie другой вкладки принадлежит другому покупателю, локальный вход сбрасывается и исходный запрос не повторяется. Запоздавшие refresh/401 не перезаписывают токен нового входа.
- Отказ refresh и logout не отправляют удаление cookie: такой ответ может прийти после нового входа в другой вкладке. Выход отзывает сессию в БД; оставшийся cookie-секрет уже непригоден и перезапишется при новом входе либо истечёт через 7 суток.
- Администраторский вход, секреты заведений, восстановление пароля и контактная верификация не меняются в этом этапе. Они остаются отдельными открытыми задачами.

Приёмка: PostgreSQL проверяет refresh cookie, отсутствие refresh-секрета в БД/JSON, отклонение неправильного Origin, срока и отозванных токенов, logout-all. Браузер проверяет вход, перезагрузку без JWT в storage, выход и существующий цикл заказа. Production миграции не выполняются.
