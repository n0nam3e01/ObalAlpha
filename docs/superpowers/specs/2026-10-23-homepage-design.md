# Главная Öbal: UI/UX

Запрос владельца: пересобрать главную, сделать современнее и аккуратнее, использовать Emil Kowalski и UI UX Pro Max. Название и стек сохраняются.

Выбранное исполнителем направление: тёплый, спокойный каталог. Альтернатива с крупным рекламным лендингом задерживает выбор набора; чисто табличный каталог сохраняет ощущение технического прототипа. Сочетаем короткий вводный блок, компактный поиск и товарную выдачу.

На компьютере рабочая ширина 1184px и верхняя навигация. На телефоне компактный герой, горизонтальные карточки и существующая нижняя навигация. Hero содержит оригинальную SVG-иллюстрацию пакета: это декоративная графика, а не фото реального предложения. В товарных карточках остаются только реальные фото/нейтральная заглушка.

Пустое состояние получает нормальную панель, действие обновления, контакт поддержки и три шага заказа. Не показываем фиктивные отзывы, цены, статистику, обещания наличия или времени публикации. Карта Google, адрес, авторизация, бронирование, оплата при выдаче, URL фильтров и возврат к позиции не меняются.

Оформление использует существующие coral/off-white/plum tokens и шрифт Golos Text, обе темы. Рекомендации стороннего справочника по оранжево-синей палитре и новым шрифтам не применяются из-за правил бренда. Нажатия 140–160ms, hover только для точного указателя, без прокрутки с эффектами и анимации списков; reduced motion сохраняется. Поля имеют доступные имена, элементы 44px, видимый keyboard focus.
