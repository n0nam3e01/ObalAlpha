# Главная Öbal: UI/UX

Запрос владельца: пересобрать главную, сделать современнее и аккуратнее, использовать Emil Kowalski и UI UX Pro Max. Название и стек сохраняются.

Выбранное исполнителем направление: тёплый, спокойный каталог. Альтернатива с крупным рекламным лендингом задерживает выбор набора; чисто табличный каталог сохраняет ощущение технического прототипа. Сочетаем короткий вводный блок, компактный поиск и товарную выдачу.

Поправка владельца после первого выпуска: сохраняется прежняя центральная ширина 780px, нижняя навигация видна и на компьютере, и на телефоне; верхние дублирующие ссылки удалены. На телефоне компактный герой и горизонтальные карточки. Hero содержит оригинальную SVG-иллюстрацию пакета: это декоративная графика, а не фото реального предложения. В товарных карточках остаются только реальные фото/нейтральная заглушка.

Пустое состояние получает нормальную панель, действие обновления, контакт поддержки и три шага заказа. Не показываем фиктивные отзывы, цены, статистику, обещания наличия или времени публикации. Карта Google, адрес, авторизация, бронирование, оплата при выдаче, URL фильтров и возврат к позиции не меняются.

Оформление использует существующие coral/off-white/plum tokens и шрифт Golos Text, обе темы. Рекомендации стороннего справочника по оранжево-синей палитре и новым шрифтам не применяются из-за правил бренда. Нажатия 140–160ms, hover только для точного указателя, по прямому требованию владельца восстановлен существующий useHomeScroll: плавное появление карточек и движение иллюстрации при нативной прокрутке; reduced motion сохраняется. Поля имеют доступные имена, элементы 44px, видимый keyboard focus.

Источники навыков прочитаны из оригинальных репозиториев:
- https://github.com/emilkowalski/skills/tree/main/skills/emil-design-eng
- https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Локальная копия справочников временная, в .test-runtime; к приложению новые runtime-библиотеки не добавляются.

Выбор «Вся Астана»/района заменён тематическим listbox с клавиатурой, Escape, закрытием по внешнему нажатию и озвучиванием текущего значения. Города без реальных предложений не добавляются.
